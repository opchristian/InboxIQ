Live Gmail Demo

This demo shows InboxIQ connecting to Gmail through OAuth and converting real inbox messages into structured action cards.

Private inbox data is not stored publicly. Demo mode uses sample inbox emails for safe recruiter review.

How it works

  1. 1
    Ingest messy email messages Demo uses curated sample inbox emails; Live pulls recent threads from Gmail after OAuth (readonly).
  2. 2
    AI classifies intent and priority Each message gets a category (e.g. Action Needed, Schedule) and a priority level.
  3. 3
    InboxIQ extracts deadlines, scheduling needs, and suggested replies Structured fields plus an optional draft reply appear on each card below.
